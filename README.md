# SBI家族売買記録 v3.5.12

添付されたv3.5.11とdata.zipを基準に更新しました。既存Excelのシート・セル・書式・数式・列幅を維持しています。

## GitHubから取得する場合

`dist/family_trades_v3.5.12_code.zip` がコード版です。GitHubの「Code → Download ZIP」でもソース全体を取得できます。取引台帳、PDF原本、認証設定、個人用の暗号化初期設定ファイルはGitHubへ登録していません。

元のWindows PCで新版を別フォルダへ展開し、旧アプリの最新の `data` フォルダ全体をコピーしてください。元の `data` と旧アプリは削除しないでください。既存設定をそのまま利用し、`setup_all_windows.bat` → `start_windows.bat` の順で起動します。

## Windowsで使う

1. 旧アプリとEdgeの収集処理を終了し、旧フォルダを残します。
2. 新版ZIPを**別フォルダ**へ展開します。データ同梱版は添付時点のdataを保持しています。添付後に更新したデータがある場合は、同梱dataを使用せず、旧フォルダの最新data全体をコピーしてください。フォルダ内のファイルを継ぎ足して混在させないでください。
3. `setup_all_windows.bat` を一度実行してください。Windowsの時刻データも導入します。
4. `start_windows.bat` を実行します。既存dataがあれば、更新版の初回起動でアプリ内の`backups/before_v3.5.12_日時/data`へ暗号化設定を含めて退避します。バックアップに失敗した場合は起動を停止します。
5. 口座Cを選択し「選択口座を自動取得」で確認してください。続けて四口座を取得できます。取り込みは内容確認後に確定します。

保存されたSBI・Gmail認証情報はWindows DPAPIで保護されており、元のPC・Windowsユーザーで利用してください。クラウドや別PCにコピーしても復号できません。設定済みの名義・Gmail受信先・OAuthクライアントは既定値へ上書きしません。変更は「口座・認証の設定」から行えます。

## 今回の取得処理

- 電子ポスト：報告書閲覧後の中継画面、iframe内のフォーム、新規タブ、遅延SSOを扱います。候補が曖昧なら自動選択せず停止します。手動で同じEdgeの一覧を開いた場合の復帰経路も維持しました。
- PDF：同日・同名の別書類を区別し、選択した書類内のPDF操作だけを実行します。星付けはしません。前の書類の遅延応答や別書類と同じPDFを検出した場合は完了扱いにしません。
- 取得後：PDFの構造・終端・ページを確認し、本文から判別できる書類種類も照合します。本文の書類名が確認できないPDFは、その事実を取得結果に残します。台帳登録は別の解析・名義確認を通します。
- 件数：一覧の表示件数・検出件数・ページ末尾を照合します。欠落・超過・不明は全件成功にしません。失敗した処理でも保存済みPDFを保持します。
- 再実行：旧版の「保存済み」対応表は誤対応の可能性があるため、スキップの根拠にしません。新しい安定した書類IDとメタデータ、ファイルのハッシュを確認できたキャッシュだけを使います。IDを確認できない書類は再取得します。

## 資産とNISA

通常の取得ではPDF保存後に、円口座サマリー・My資産・外貨建口座を取得します。電子ポストを経由しない「選択口座の資産だけ自動取得」も追加しました。この操作は保存PDFの取り込みをしません。

取得対象はNISA成長・つみたて枠、国内株式等の円評価、外国株式の円評価、円現金、外貨現金の円評価、米ドル現金の元通貨額です。画面に表示のない値は未取得のままです。買付余力を現金に代用せず、ドル残高を円として転記しません。My資産の「預り金を除外」が有効なら表示フィルターを解除して読み取ります。

「取得した資産を確認」で元通貨のドル額と取得日時を確認できます。Excelの既存の円評価欄には円表示を確認できた値を入れます。Excelの列・通貨表示の変更はありません。今回取得した現在値を、過去の月末・月初の残高へ流用しません。同日の手動記録も保持します。

## 確認範囲と制限

ローカルの回帰テスト、実Chromiumで通信先を模擬画面に差し替えたテスト、添付PDFと台帳の再構築、旧版とのExcel内部XML比較を行っています。詳細は `検証結果_v3.5.12.md` に記録します。

**実際のSBI画面・Windows実機での全自動成功は未確認です。** 添付のMy資産画面には外国株式・米ドルの表示がなく、この部分は模擬画面での確認です。自動移動失敗後の手動復帰を全自動成功とは数えていません。

PDF保存と取引明細の解析は別です。外国株式・外国債券の取引明細と債券利金通知は従来どおり解析未対応で、取り込み確認に対象外として表示します。年次報告書と税額0円の通知も取引追加の対象外です。PDFそのものは保存します。父口座EのSBIログイン・資産自動取得は行いません。

失敗時は「PDF取得結果一覧」と `data/diagnostics` の `auto_*.txt`・`navigation_*.json` を確認してください。画像や資産JSONには口座情報が含まれる場合があります。セッションURL・認証コード・パスワードは新しい移動診断へ出力しません。

## 開発・テスト

既存のチェックアウトを使います。このクラウドタスクのためにGit worktreeを追加する必要はありません。元データはテストに直接書き込まず、隔離コピーを使用してください。

```sh
cd /workspace/API
python3 -m venv /workspace/.venv
/workspace/.venv/bin/python -m pip install -r requirements_pdf.txt -r requirements_epost.txt -r requirements_gmail.txt
/workspace/.venv/bin/python -m unittest discover -v
```

Windowsは `run_tests_windows.bat` で全テストを検出します。ブラウザー試験は既存Edge/Chromiumを自動検出し、必要なら `SBI_TEST_BROWSER` で実行ファイルを指定できます。ブラウザーがない場合のスキップは合格件数と区別してください。一部の旧DOM試験はNode.jsがない場合にスキップします。テストは実際のSBI・Gmailへ接続しません。
