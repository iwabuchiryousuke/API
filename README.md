# SBI家族売買記録 v3.6.1

今回の「取引シート見本.xlsx」を基準に、出力書式とボタン配置を修正しました。

- 添付の列幅・行高・フォント・色・書式・表示倍率を採用。先頭列や行の固定、自動拡幅・自動行高調整を外しました。
- 配当まとめはK～Xへ配置し、確認状態を削除。銘柄設定で表示順を保存できます。
- 日付は日本時間の今年だけを月/日で表示。今後1か月以内の予定をすべて見本の赤で強調します。
- 支払日不明は「未定」、根拠のある無配は「無配」。支払日行の右側にだけ実績・予想配当金額を表示します。
- Yahoo時系列の終値とInvesting.com配当情報を、取得・保存PDF反映・Excel出力時に更新します。
- 設定メニューは指定の5項目だけ。一覧上へ保存PDF反映・銘柄設定・出力フォルダの3ボタンを配置しました。

現在のアプリを終了し、`update_windows.bat` で `dist/family_trades_v3.6.1_code.zip` を適用後、`start_windows.bat` で起動してください。更新前コードと新版初回起動時のdataをバックアップします。現在の最新dataを維持してください。

操作・書式・公開情報取得・更新手順は[はじめに_v3.6.1.txt](はじめに_v3.6.1.txt)、検証範囲は[検証結果_v3.6.1.md](検証結果_v3.6.1.md)と `dist/verification_summary.json` を参照してください。

同日取引の合算とK～Mの計算は維持しています。原本PDF・DBの明細・証跡を合算して置換しません。月末月初の現金復元や無人予約は行いません。今回取得できない現金・NISAは空欄です。

公開情報の通信失敗は実績データを壊さず、確認できない価格は空欄、支払日は未定で出力します。1日が休場日なら、1日終値を別日で代用しません。公開予定から個人の入金実績を作りません。

実SBI・Gmail・Windows実機・Windows版Excelは未検証です。このクラウドから指定のYahooとInvesting.comへの実接続は403で制限されています。HTML/JSONのテスト応答、表計算ソフトでの再計算、添付見本との書式比較を検証し、実ページ接続の結果と区別します。

配布コードと架空データ見本には、添付Excelの実取引や認証設定を含めません。旧形式の `reference/excel_layout.json` は更新互換性のため保持し、新しい書式は個人の値を取り除いた `excel_template_v361.py` で実装しています。

開発時は `python -m unittest discover -v`、Windowsは `run_tests_windows.bat` を使用します。ブラウザー検証にはChromium/Edge、表計算の実再計算検証にはLibreOfficeとopenpyxlを検出します。Office用の検証依存関係はアプリの実行時には不要です。
