# SBI家族売買記録 v3.6.2

ボタンを小さく整理し、取引一覧と今後のカレンダーを並べました。出力対象月の入力は外し、全登録データを扱います。

- 全データ自動取得：A～DのPDF・円・米ドル・NISAを取得して確認・出力。
- 横並び5ボタン：保存PDFを反映、銘柄設定、出力フォルダを開く、父のPDF取り込み、税還・利息を手動で追加。
- アプリの予定は過去を除外し、近い順に表示。保有数0と確認できる銘柄はアプリ・Excelのカレンダーから除外します。
- カレンダーの配当金額は数字だけ。元の実入金明細・集計・累計は維持します。
- X列を月初終値へ変更。月初が休場日なら最初の取引日の終値を照合し、実際の価格日と出典をセル注記に記録します。2026年11月は日曜の1日ではなく、2日が対象です。

時差によって月初の日次データが前月へずれるケースを修正しました。対象日のデータがない場合は後日の株価で代用せず、当日16時前の未確定値も採用しません。旧版の暦の1日の値は保存したまま、対応する日付・出典が確認できる場合だけ再利用します。

添付のExcelの列幅・行高・配置・色・倍率、固定なしの書式を維持します。既存DBの原明細やPDF証跡を合算して置換しません。変更前にバックアップし、更新時もコードとdataを退避します。

現在のアプリを終了し、`update_windows.bat`で`dist/family_trades_v3.6.2_code.zip`を適用後、`start_windows.bat`で起動してください。新しい実行時依存関係はありません。現在の最新dataを維持してください。

操作・日付の意味は[はじめに_v3.6.2.txt](はじめに_v3.6.2.txt)、検証範囲は[検証結果_v3.6.2.md](検証結果_v3.6.2.md)と`dist/verification_summary.json`を参照してください。

指定のYahoo・Investing.comへの実接続はこの環境のプロキシで403でした。実サイトの最新数値、実SBI・Gmail・Windows実機・Windows版Excelは未検証です。テスト応答とLibreOfficeの実再計算、書式・データ保全の独立比較を検証し、実接続の結果と区別します。

コードZIPに個人data・PDF原本・添付の実取引・認証設定を含めません。出力見本は架空データだけです。開発時は`python -m unittest discover -v`、Windowsは`run_tests_windows.bat`で試験できます。
